  Boolean: It gives only TRUE or FALSE values
  Null: It  means nothing or empty values will be there but not ZERO
  Undefined: These means a variable is exist but it doesn't have the value or value is not assigned
   Symbol: Even though the data is same it will create the unique identity or variable
